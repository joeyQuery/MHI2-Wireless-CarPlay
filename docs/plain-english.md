# MHI2 Wireless CarPlay

[**Plain English**](plain-english.md) · [**Technical English**](../README.md)

This project is investigating whether Wireless CarPlay can be enabled on Audi MHI2 systems using the hardware and software already in the unit.

### What we know

The firmware contains Bluetooth, Wi-Fi, iAP2, AirPlay and CarPlay components that are relevant to Wireless CarPlay.

### What we do not know yet

The complete wireless connection between those components has not been proven. Wireless CarPlay is **not yet working or proven** by this project.

This repository records the evidence and the remaining work.
